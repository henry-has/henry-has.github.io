How it works

S is how many groups sit in series (it sets the voltage). P is how many cells sit side by side in each group (it sets the capacity and current). A 7S3P pack is 7 groups of 3 cells: 25.2 V, 12.6 Ah.

You weld group S1 first, then S2, and so on. Each group should be one touching cluster, and it has to touch the group before it so current can flow along the chain from PACK − to PACK +.

Neighbouring cells get nickel strip automatically. Strips join a group to itself and to the next group in the series. Each strip is about 2 mΩ per cell pitch; each cell is 15 mΩ. The pack runs at 15 A per cell.

Score = ½ resistance (vs a perfect busbar) + ½ sharing (how evenly each group's cells carry current), multiplied by integrity. Integrity drops if a group is split into islands that don't touch.

The groups alternate orientation, so the strips sit on alternating faces. Flip the pack to see both.
