Pack Daily

Lay out a cylindrical-cell battery pack so current shares evenly.
  1. Goal: split the cells into S groups of P cells (e.g. 7s3p = 7 groups of 3). Cells inside a group are in parallel; groups are wired in series in number order, 1 → 2 → 3 …
  2. Paint a group: left-click or drag over cells. When a group is full you automatically move on to the next one. Start a drag on a cell that's already in a group (or click its chip) to extend that group.
  3. Erase: right-click or drag over cells (touch: use Erase mode). Groups don't have to be touching, but touching cells in the same group share a plate, and a lonely cell carries little current.
  4. Interconnects: wherever a cell of group n touches a cell of group n+1, a nickel strip joins them. Odd links (1–2, 3–4…) sit on Side A, even links (2–3, 4–5…) on Side B, so alternating groups are flipped. More strips = lower link resistance.
  5. Glow: red = only one strip (bottleneck), amber = two, dashed = none, so no current can flow at all. A cell with no strips carries nothing.
  6. Score: we simulate the resistor network. Aim for every cell to carry the same current and every link to have similar resistance. ★★★ ≥ 95%.
